# OmniGen Studio

## Tải App

Tải file cài đặt Windows tại trang Releases:

[Download OmniGen Studio EXE](https://github.com/Anhquocqh25/Omnigen-Studio/releases/latest)

File cần tải:

```text
OmniGen-Studio-Setup-0.1.1.exe
```

## Cài Đặt

1. Tải file `OmniGen-Studio-Setup-0.1.1.exe`.
2. Mở file vừa tải.
3. Nếu Windows hiện cảnh báo bảo mật, chọn **More info** rồi chọn **Run anyway**.
4. Chọn thư mục cài đặt và bấm **Install**.
5. Mở **OmniGen Studio** sau khi cài xong.

## Sử Dụng Nhanh

1. Mở tab **Configuration**.
2. Nhập Google Cloud Project ID, location, API key hoặc đăng nhập Google Cloud OAuth nếu cần.
3. Dùng tab **Image** để tạo ảnh.
4. Dùng tab **Video** để tạo video.
5. Dùng tab **Builder** để chạy Workflow Editor.
6. Dùng tab **Library** để xem lại ảnh/video đã tạo và tải xuống.

## Cập Nhật App

Khi có bản mới, mở **Configuration** trong app rồi bấm:

